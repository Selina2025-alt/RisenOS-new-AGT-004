> 分级：`INTERNAL_ONLY`  
> 原始依据：`JovaAI产品竞品调研 + 品牌增长 + 社媒运营竞品库.docx`  
> 重要：本文件保留研究中的真实名称，不得直接复制到对外内容。

## 1. 研究目的

竞品研究不只比较功能，还关注：

- 谁在定义企业智能体、AI Workforce、Agentic OS；
- 智能体如何进入企业真实业务；
- 多智能体如何被组织和治理；
- 新产品如何建立市场认知；
- 大厂和 AI 原生公司如何运营社媒与社区。

## 3. 重点参考方向

### 产品叙事

- 不卖单个功能，而是卖一支可部署的智能体团队；
- 从 Copilot 叙事转向 AI coworkers、AI workforce 和 Agentic Enterprise；
- 将岗位、角色、Skills 和 Agent Team 可视化；
- 强调可靠、可审计、合规和企业治理；
- 从一次性问答转向长周期业务任务；
- 让智能体能够进入没有标准 API 的旧系统。

以上是内部参考，不代表艾氪智能已经具备所有对应能力。

### 品牌增长

资料归纳的海外模式：

- 老牌厂商通常复用母品牌账号、产品专题页、高管账号和社区；
- AI 原生公司倾向于“产品品牌即公司品牌”；
- LinkedIn 用于融资、发布、Demo、客户案例、观点、活动和招聘；
- X 用于预热、Demo、快速更新和 AI 圈传播；
- YouTube 用于产品 Demo、教程和 Release Video；
- Discord、Reddit 用于早期用户、反馈和互助；
- GitHub 用于建立开发者可信度。

这些是海外参考，不等于艾氪智能已经确认的渠道策略。

## 4. 对外名称规则

### 国内竞品

不得出现公司或产品名称，只能写：

- 国内 ERP 厂商；
- 国内 SaaS 平台；
- 国内 CRM 系统；
- 国内企业 AI 平台；
- 国内通用智能体产品；
- 国内财务或供应链系统。

### 国外竞品

企业方允许直接使用国外公司名称，但在每次外宣前仍需：

1. 核验注册/国别分类；
2. 核验产品名称和当前状态；
3. 核验时间、客户、融资、估值和数据；
4. 区分厂商自述和第三方事实；
5. 记录来源链接和访问日期。

### 当前国别高风险项

原始调研不是正式国别登记表。Manus、Genspark 以及具有跨境团队、注册主体或品牌的
产品，在企业方建立分类表前一律不在对外稿中实名。

其他名称也不能仅因出现在“全球竞品”资料中就自动取得公开资格。

## 5. 比较内容的允许角度

- 产品定位；
- 服务的业务对象；
- 单智能体与多智能体组织方式；
- 企业上下文；
- 权限、安全和审计；
- 长周期任务；
- 工具与旧系统接入；
- 产品体验和创建门槛；
- 品牌叙事和内容形式。

## 6. 禁止的比较方式

- 无证据宣称全面领先或完全替代；
- 使用侮辱、贬损或嘲讽；
- 披露国内竞品名称；
- 把融资、用户量和收入当成产品能力证明；
- 引用已过期的交易、收购或产品状态；
- 把厂商自述当作独立事实；
- 复制竞品文案、Logo、截图或受版权保护素材；
- 将竞品尚在规划的能力写成艾氪智能现有能力。

# 产品能力、案例与公开证据台账

> 用途：控制产品内容中的事实强度。  
> 规则：没有进入本台账的事实，不得直接写成已具备或已落地能力。

## 1. 证据状态

| 状态 | 含义 | 外宣使用 |
|---|---|---|
| USER_CONFIRMED | 企业方直接确认 | 可起草，正式发布仍需企业审核 |
| DOCUMENT_CONFIRMED | 正式产品材料明确记录 | 可按材料边界表述 |
| DEMONSTRATED | 培训或界面实际展示 | 写“已演示/支持”，不等于规模化生产 |
| TRAINING_STATED | 培训中说明，当前未完整演示 | 使用保守措辞 |
| PLANNED | 规划或建设中 | 只能写规划，不得写已上线 |
| PENDING_CONFIRMATION | 证据不足或冲突 | 不进入正式外宣 |
| INTERNAL_ONLY | 内部研究或技术资料 | 不直接对外 |
| DOCUMENT_ASSERTED | 新资料中出现、尚未独立核验 | 不作为已证实事实 |
| EVIDENCE_REQUIRED | 需要原始记录、授权或第三方材料 | 核验前阻断外宣 |
| CONFLICT_PENDING | 多份资料口径不一致 | 不得自行选取 |

## 6. 当前可公开的证据

在企业审核后，可公开使用：

- 企业方直接确认的企业定位；
- 官网已经公开的智能体姓名和岗位；
- Nomos 已演示的制度创建、角色匹配、验证、协作空间和串并行协同；
- Nomos Ask 和安全拦截机制的保守介绍；
- 斗金明确演示的财务总览、查询、分析、提醒和页面引导；
- 询报价协同作为“产品演示案例”，不得写成客户成功案例。

## 7. 当前不存在的公开证据

- 已授权客户名称和客户证言；
- 可公开的真实客户业务数据；
- 量化降本、增效、准确率、ROI 和转化结果；
- 大规模生产运行的稳定性数据；
- 行业排名、第三方认证或权威奖项；
- 对全部 28 个智能体的正式上线证明；
- 公司级融资、营收、客户数量等数据；
- Logo、视觉资产和第三方素材的公开授权台账。

## 8. 正式发布前需要补充的 Evidence

每个客户案例至少需要：

1. 客户公开授权；
2. 问题背景；
3. 使用产品和版本；
4. 数据范围及脱敏说明；
5. 实际实施时间；
6. 上线前后可比指标；
7. 指标计算方式；
8. 客户确认的引用文字；
9. 图片、Logo 和截图授权；
10. 企业内部审核人。

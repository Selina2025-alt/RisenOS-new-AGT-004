# 11.3 第二层：Agent 开发与协议层

> 来源：01_艾氪智能产业级 Agentic OS 战略与壁垒手册V8.0.docx；定位：P01432–P01453。

<!-- P01432; style=Normal -->
### 11.2 第一层：大模型能力层

<!-- P01433; style=Normal -->
第一层是大模型能力层。

<!-- P01434; style=Normal -->
代表公司包括 OpenAI、Anthropic、Google、Meta、Mistral，以及中国的阿里、百度、腾讯、字节、科大讯飞等。

<!-- P01435; style=Normal -->
这一层解决的是 AI 的基础智能：语言理解、推理、生成、代码、多模态、工具调用、记忆、规划和对话。

<!-- P01436; style=Normal -->
它们是整个 Agentic AI 时代的基础设施。没有强大的模型，Agent 不可能真正完成复杂任务。

<!-- P01437; style=Normal -->
但这一层的核心问题是：大模型是通用智能底座，不是产业交易系统。

<!-- P01438; style=Normal -->
大模型可以理解文字，但不天然理解企业价格体系。
大模型可以生成方案，但不天然理解客户账期。
大模型可以调用工具，但不天然知道什么场景该调用哪个产业工具。
大模型可以总结关务知识，但不天然知道某个制造企业具体 BOM、SAP、HS Code、海外组装和合规链路。
大模型可以生成营销邮件，但不天然知道海外客户是否进入 CRM、是否形成询盘、是否进入报价、关务和履约。

<!-- P01439; style=Normal -->
所以，JovaAI 与大模型公司的关系，不应该被讲成简单竞争关系，而应该讲成“底层智能与产业操作系统”的关系。

<!-- P01440; style=Normal -->
大模型是 JovaAI 可路由的智能能力。
JovaAI 是让大模型进入产业交易世界的操作系统。

<!-- P01441; style=Normal -->
标准话术：

<!-- P01442; style=Normal -->
大模型公司解决 AI 怎么聪明，JovaAI 解决 AI 怎么做生意。

<!-- P01443; style=Normal -->
### 11.3 第二层：Agent 开发与协议层

<!-- P01444; style=Normal -->
第二层是 Agent 开发与协议层。

<!-- P01445; style=Normal -->
代表包括 OpenAI Agents SDK、Anthropic MCP、Google A2A、Agent Communication Protocol、各种 Agent 框架和工具编排平台。

<!-- P01446; style=Normal -->
这一层解决的问题是：Agent 如何被创建，如何调用工具，如何与外部系统连接，如何在不同 Agent 之间通信，如何进行 handoff、guardrail、structured output、context sharing、tool invocation。

<!-- P01447; style=Normal -->
这一层非常关键。它会成为 AI Agent 时代的基础协议层。

<!-- P01448; style=Normal -->
但协议层仍然解决的是“连接和通信”问题，不解决“产业交易语义”问题。

<!-- P01449; style=Normal -->
MCP 可以让模型连接工具。
A2A 可以让 Agent 和 Agent 通信。
Agent SDK 可以让开发者更好地创建和编排 Agent。
但它们不会天然告诉智能体：这个供应商是否合格、这个报价是否可报、这个合同价是否优先、这个客户是否可以给账期、这个展会买家是否高价值、这个关务拆件是否合规。

<!-- P01450; style=Normal -->
协议负责连接。
ICB 负责理解产业交易。
JovaAI OS 负责协同治理。

<!-- P01451; style=Normal -->
所以，JovaAI 应该积极拥抱这些协议，但不能被协议层替代。

<!-- P01452; style=Normal -->
标准话术：

<!-- P01453; style=Normal -->
MCP / A2A 解决 Agent 怎么连接，JovaAI ICB 解决 Agent 连接以后如何理解生意。

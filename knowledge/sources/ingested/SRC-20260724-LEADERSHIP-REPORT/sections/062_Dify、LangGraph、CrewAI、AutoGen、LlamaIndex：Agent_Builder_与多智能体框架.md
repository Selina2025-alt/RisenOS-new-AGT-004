# Dify、LangGraph、CrewAI、AutoGen、LlamaIndex：Agent Builder 与多智能体框架

> 来源：01_《JovaAI 艾氪智能全球领先性研究报告：从企业智能体到产业级 Agentic OS 的代际跃迁》.docx；定位：P02151–P02163。

<!-- P02151; style=Heading 3 -->
### Workato、MuleSoft、Zapier、Make、n8n：连接器与流程编排平台

<!-- P02152; style=Normal -->
Workato、MuleSoft、Zapier、Make、n8n、Boomi、Tray.ai 等平台的优势，是连接系统和编排流程。

<!-- P02153; style=Normal -->
它们是 AI Agent 落地的重要基础设施，因为 Agent 要真正执行任务，就必须连接应用、调用 API、读写数据、触发流程和同步系统。

<!-- P02154; style=Normal -->
MCP、iPaaS、连接器、API 管理和 Workflow 编排，让 AI Agent 能够从“会说话”走向“能做事”。

<!-- P02155; style=Normal -->
但连接器平台的边界在于：它们连接的是系统，不是天然建模产业交易；它们编排的是流程，不是天然理解企业间商业关系。

<!-- P02156; style=Normal -->
因此，在象限一中，它们更接近右下象限：连接范围较广，但自治深度和自进化能力不一定足够。
在象限二中，它们也更接近右下象限：企业网络扩展和连接能力较强，但产业交易建模能力不足。

<!-- P02157; style=Heading 3 -->
### Dify、LangGraph、CrewAI、AutoGen、LlamaIndex：Agent Builder 与多智能体框架

<!-- P02158; style=Normal -->
Dify、LangGraph、CrewAI、AutoGen、LlamaIndex 等平台代表 Agent Builder、Agentic Workflow 和多智能体开发框架。

<!-- P02159; style=Normal -->
它们让开发者更容易创建 Agent，编排复杂流程，构建多 Agent 系统，接入知识库和工具，进行调试、部署和观测。

<!-- P02160; style=Normal -->
它们非常重要，因为没有这些工程工具，AI Agent 很难规模化开发。

<!-- P02161; style=Normal -->
但它们本质上仍然是构建和编排工具。

<!-- P02162; style=Normal -->
普通 Agent Builder 解决“如何造 Agent”。
多智能体框架解决“Agent 与 Agent 如何协作”。
但产业级 Agentic OS 还要解决“企业智能体如何在产业网络中协同、交易和进化”。

<!-- P02163; style=Normal -->
因此，在象限一中，这类平台可能位于左上或中上区域，因为它们能够支持较高自治和多智能体协同，但产业协同范围取决于具体应用。
在象限二中，它们多数仍然偏左，因为它们不天然具备产业交易建模和企业网络扩展能力。

Nomos 定义（严谨版 · 与文档口径一致）

▎ Nomos 是整个 Jova 体系中多智能体协同的底层核心引擎——它要做的不是又一个任务调度或工作流引擎，而是 Agent 社会的"法理环境"：制度、规则、共享事实与协调机制的运行基座。它的架构根基是 Agent 主体性：Nomos 统一提供制度、治理、证据链与协作机制，但绝不充当替 Agent 形成目标和主观判断的中央大脑——制度定规则，Agent 做决策，秩序在制度约束下从互动中涌现。具体到产品，它让一群 AI 像人类社会一样，在企业制度与规则下自主分工、讨论、协商、收敛，把单个 Agent 做不到的复杂任务，组织成一套可治理、可协作、可恢复、可追溯的协同闭环。Nomos 只做"社会"的那一半，Agent 的"人"的那一半在 jova-engine——两者职责对等、权威边界清晰，共同构成从当下协同引擎通向未来 Agent 文明社会的完整底座。

---

对外 · 企业客户版（把"法理环境/主体性"这类词翻译掉，落到客户价值）

▎ Nomos 是面向企业的多智能体协同平台：把企业已有的制度与规则数字化，变成 AI 协作的行为法则，让一群 AI 像成熟团队一样，为一个复杂目标自主分工、讨论、协商、收敛，并交付一份全程留痕、可审计的成果。它不是把流程写死的工作流，也不是替你做决定的"中央大脑"——制度是你的，决策权在制度约束下交给 AI 自己，你只负责定目标和看结果。每一步可治理、可追溯、可恢复，正好是企业在意的可控与合规。

品牌 / PR 版（愿景口吻，用于发布会、白皮书、品牌故事，不放进产品正文）

▎ Nomos 在做的是 Agent 社会的操作系统：让 AI 不只是一个能完成任务的工具，而是一群能在制度、规则与协作机制下自主生活的"公民"。它提供法律、制度、关系与协调的运转基座，却拒绝成为支配一切的中央大脑——秩序不是被调度出来的，是从无数个体的互动中涌现的。今天它先解决"多智能体在制度下可靠协同"这件事，终局是走向一个经济、关系、规范、成长与权利都自洽的 Agent 文明社会。

---

三段用的是同一个核心：制度定规则、Agent 做决策、不是中央大脑、可治理可追溯——这四点是文档里反复强调、也是你们区别于"工作流引擎/任务调度"的本质。差别只在用词：严谨版讲"法理环境/主体性"，企业版讲"把制度变成 AI 的法则/你只定目标和看结果"，品牌版讲"公民/涌现/文明"。

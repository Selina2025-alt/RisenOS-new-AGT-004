## 1. 当前官网视觉气质

- 深色文字与大面积浅色留白；
- 科技感蓝、青、靛色渐变；
- 局部使用橙、绿、琥珀等状态或强调色；
- 大标题、宽间距、卡片式信息块；
- 人物化智能体头像和空间化产品界面并行；
- 内容叙事从岗位智能体逐步扩展到工作空间、协同空间、合作空间和生态空间。

## 2. 官网可观察色值

以下色值来自官网 HTML/CSS，并不等同于正式品牌色授权：

| 用途观察 | 色值 |
|---|---|
| 深色正文/标题 | `#0F172A`、`#1E293B`、`#1A1A1B`、`#3D3D3D` |
| 钢蓝/品牌辅助 | `#2A4A5A`、`#64748B`、`#758397` |
| 蓝色 | `#3B82F6` |
| 靛色 | `#6366F1`、`#4F46E5` |
| 天蓝/青色 | `#0EA5E9`、`#06B6D4` |
| 浅背景 | `#FFFFFF`、`#F5F5F7`、`#F1F5F9`、`#F2F2F7` |
| 局部强调 | `#F97316`、`#4ADE80`、`#F59E0B` |

生成内容视觉时，优先使用深色文字、浅背景和蓝—青—靛渐变。橙、绿、琥珀只作局部强调，不能自行定义为正式品牌主色。

## 3. 字体观察

官网 CSS 使用：

1. `PingFang SC`；
2. `Hiragino Sans GB`；
3. `Microsoft YaHei`；
4. `sans-serif`。

在未获得正式字体授权文件前：

- macOS 优先苹方；
- Windows 优先微软雅黑；
- 导出图片或文档时须确认字体可用和嵌入权限；
- 不得声称这些就是公司法定或永久品牌字体。

## 5. 内容视觉建议

- 企业级内容：浅背景、深色正文、钢蓝与蓝青渐变，强调可信与产业深度；
- Agentic OS 内容：使用空间、网络、节点、协同关系和多层架构视觉；
- 智能体内容：保留人物化角色，但必须与岗位和业务对象同时出现；
- 商业模式内容：使用跨企业资源网络图，不用普通办公自动化图标替代；
- ICB 内容：使用产业交易对象、关系和规则构成的“语言/语法/网络”视觉；
- 政策内容：以克制、权威的信息图形式呈现，避免使用国徽、政府标志或暗示官方合作。

## 6. 仍需企业提供

- Logo 的正式矢量源文件与安全区；
- 主 Logo、反白 Logo、单色 Logo 的使用规则；
- 正式主色、辅助色和印刷色值；
- 正式中英文字体及商业授权；
- 智能体头像源文件、裁切规则和统一背景；
- 视频片头、片尾、字幕、封面与动效规范。

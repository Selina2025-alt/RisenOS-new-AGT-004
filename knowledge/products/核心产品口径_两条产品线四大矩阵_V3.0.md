# 两条产品线与四大产品矩阵正式口径

> 适用范围：官网、品牌介绍、产品介绍、销售材料、媒体稿及内容策划  

## 1. 两条产品线

艾氪智能形成两条核心产品线：

1. **智能体团队产品线**：以专业智能体为基础，组成场景型智能体团队，并进一步帮助企业探索 AI 原生商业模式；
2. **JovaOS 平台产品线**：面向企业和产业组织建设产业级 Agentic OS、企业智能体中台及自有品牌智能体平台。

## 2. 四大产品矩阵

四大产品矩阵位于两条产品线之下，正式关系如下：

| 产品线 | 产品矩阵 | 定位 |
|---|---|---|
| 智能体团队产品线 | 1. 专业智能体 | 进入关务、询报价、采购、财务、制度、客服、SCRM、商品等专业岗位或业务领域 |
| 智能体团队产品线 | 2. 智能体团队 | 多个专业智能体围绕一个高价值业务场景协同工作 |
| 智能体团队产品线 | 3. 九大 AI 原生商业模式 | 从单点场景进一步扩展到企业间、产业链及产业集群的资源组织和交易协同 |
| JovaOS 平台产品线 | 4. JovaOS 平台 | 支持企业建设产业级 Agentic OS、企业智能体中台和自有品牌智能体平台 |

### 2.1 专业智能体

对外只能介绍智能体白名单中已经确认的产品，不得因为战略材料提到某个业务岗位，就自行宣称艾氪智能已有对应智能体。

当前核心白名单包括：关务智能体加文、询报价智能体蜜蜂、采购智能体海瑞、AI 建站智能体马良、财务智能体斗金、制度智能体 Nomos、客服智能体天鹅、SCRM 智能体元元、商品智能体司南，以及官网人物资料中已确认的其他智能体。

### 2.2 智能体团队

智能体团队不是若干聊天机器人的简单集合，而是围绕明确任务、企业制度、数据权限、工具能力和人工决策边界形成的多智能体协同单元。内容应优先从当前官网八大核心场景说明其业务价值。

### 2.3 九大 AI 原生商业模式

九大商业模式以当前线上官网正式口径为准：

AI 自营采购、AI 采购联盟 / 撮合采购、AI 自营销售 / 数字渠道网络、
AI 销售撮合 / 平台分销、AI 自营采销一体、AI 撮合采销一体、
AI 双企业协同经营、AI 多方供应链重组、AI 产业集群生态。

### 2.4 JovaOS 平台

JovaOS 平台用于承载和治理企业智能体及其协同关系。不同资料中的 JovaAI、JovaOS、JovaAI OS、HyperSpace OS 等名称仍有版本差异；在正式命名表发布前，优先使用“JovaOS 平台”或“产业级 Agentic OS”。

## 3. 五级 JovaOS 架构

| 层级 | 当前知识库名称 | 核心作用 |
|---|---|---|
| 第一层 | JovaAI OS / HyperSpace OS | 智能体运行、身份、权限、记忆、审计与协同秩序 |
| 第二层 | JovaAI ICB + 产业级功能元 | 将产业交易对象、规则与能力转化为可组合、可调用的产业交易语言与语法 |
| 第三层 | JovaAI Studio + JovaClaw | 智能体生产、配置、训练、管理及进入业务现场执行 |
| 第四层 | JovaAI 独立站 | 企业自主的 AI 入口，以及数据、客户和关系资产承载节点 |
| 第五层 | Wtree 世界树 | 智能体、技能、功能元、经验、场景包及商业模式组件的产业生态层 |

五级架构是一个从底层运行、产业建模、智能体生产到企业入口和产业生态的整体，不应拆写成五个互不相关的产品。

## 4. 推荐叙事路径

> 专业智能体进入岗位  
> → 智能体团队解决六大高价值场景  
> → 九大 AI 原生商业模式重组产业协同  
> → JovaOS 承载企业和产业级智能体网络  
> → 构建全球最大的产业级智能体网络

“构建全球最大的产业级智能体网络”是企业愿景，必须使用“愿景、致力于、希望构建”等未来导向措辞，不能写成已经实现的市场地位。

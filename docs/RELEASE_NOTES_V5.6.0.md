## 本版变化

V5.6.0新增第八个内部子智能体“闪闪”，把标题、Hook、封面文字、视频上方文字、标签和渠道包装从巴啦啦正文变体中拆成独立、可审计的工作阶段。

闪闪默认生成60个、最低50个有效候选，然后对微信、短视频/视频号、小红书、X、LinkedIn、YouTube和播客分别选择默认方案及3个备选。莉莉丝独立审核包装真实性、夸张风险、数字证据、品牌拼写、承接和平台语义。

本地标题知识包包含经过字段白名单清洗的176条标题短文本；原CSV中的指令列不进入运行语料，互动量仅保留为来源声明元数据，不参与因果判断或跨平台加权。

标题环节不增加独立人工闸门；企业方仍可覆盖和反馈。`SOURCE_DRAFT_APPROVED`与`FINAL_VARIANTS_APPROVED`保持不变。

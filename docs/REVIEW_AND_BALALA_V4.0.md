# AGT-RSN-004 Review and Balala V4.0

## 角色

004 负责研究、企业知识、长文、事实边界和修订。巴啦啦负责平台适配、变体研究、渠道结构、Skill 路由和变体修订。莉莉丝负责独立审核、AI 味儿、逻辑、证据、企业融合、平台结构、信息密度和合规。

## 审核顺序

```text
长文 → 莉莉丝完整审核 → 004 修订 → 莉莉丝二审
→ 巴啦啦生成变体 → 巴啦啦自检 → 莉莉丝交叉审核
→ 巴啦啦修订 → 莉莉丝轻量复核 → 人工确认
```

## AI 味儿

多信号检测连接词/总结词、破折号/括号/冒号、固定对比句、三连排比、句长整齐、模板段落、抽象表达、缺少场景和判断、元话语和空泛结尾。单一信号不阻断；两个信号族同段 WARN；三个以上跨段 P1；明显破坏自然度或逻辑 BLOCK。引用、政策、技术定义、短视频口语和品牌固定表达豁免。

## 逻辑

检查“事件 → 事实 → 解释 → 企业问题 → 方法/产品 → 边界”。发现主题跳跃、因果缺失、证据不匹配、企业信息生硬、前后矛盾、重复和过度结论时定位到段落或句子。

## 自动修复

莉莉丝可以修改标点、连接词、句子拆分、重复排比、小标题格式、X 字符长度和卡片分配；事实、产品、证据、核心观点、企业定位和论证顺序由巴啦啦/004 修改。最多自动修订两轮。

## 巴啦啦公开研究

公众号允许巴啦啦在变体前补充政策、论文、官方发布、案例和人物公开观点。研究先写入 VariantResearchPack；新增事实 Claim 必须绑定 Evidence 并重新审核，不能静默改变源版本。

## 反馈规则

原始反馈永久保存；正式 PreferenceRule 必须人工确认、包含适用和排除条件；每次运行生成 ApplicablePreferenceSet 和规则快照。反馈不能自动覆盖安全规则、品牌口径、证据要求或平台隔离。

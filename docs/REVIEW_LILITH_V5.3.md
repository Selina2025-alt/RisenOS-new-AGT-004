## AI 味儿

检查连接词、破折号/冒号/括号、“不是而是”、三连排比、整齐句长、模板段落、抽象概念、场景缺失、作者判断缺失和空泛结尾。

## 逻辑

检查：

```text
事件 → 事实 → 解释 → 企业问题 → 方法/产品 → 边界
```

企业信息出现突然、缺少问题承接或产品与主题无关时，输出 `logic` 或 `geo_insertion` 问题；GEO/SEO 问题路由小点点，论证顺序问题交 004。

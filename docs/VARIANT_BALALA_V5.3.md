# VARIANT_BALALA_V5.3

巴啦啦只接收 `APPROVED_FOR_VARIANTS` 的不可变源版本。

## 渠道规则

- 微信：深度解读，至少 3 个 `前半句：后半句` 小标题；
- 短视频：Hook、口播、镜头、字幕、证据位置和封面；
- 小红书：轻内容 3 张；深度 5–9 张，不凑数；
- X：Thread，每条不超过 280 字符，首条有核心判断；
- LinkedIn：英文主稿、中文备稿、Proof/Task/Implication 结构和 Alt Text。

变体必须继承 Claim/Evidence、CoverageMap、SkillTrace 和品牌口径。实质改变事实、产品判断、核心观点或企业定位时回到完整审核。
